# 采购退货 - 关联订单字段隐藏修改说明

**修改日期**：2026-05-12
**需求来源**：客户反馈
**修改人员**：Claude Code

---

## 一、需求说明

客户要求在采购退货页面隐藏"关联订单"字段，无论是"按入库单退货"还是"按库存退货"模式，都不需要显示该字段。

### 业务背景

采购退货目前支持两种模式：
1. **按入库单退货**（returnMode=10）：从原采购入库单选择可退明细
2. **按库存退货**（returnMode=20）：直接从产品库选择商品退货

这两种模式都不需要关联采购订单，因此"关联订单"字段应该隐藏。

## 三、后端兼容性

### 3.1 数据库字段

后端数据库表 `erp_purchase_return` 和 `erp_purchase_return_items` 中的 `order_id` 和 `order_item_id` 字段**保持不变**，仍然存在但允许为 NULL。

相关 SQL 脚本：
- `sql/mysql/erp_purchase_return_v8_nullable_order.sql` - 主表 `order_id` 可空
- `sql/mysql/erp_purchase_return_items_v8_nullable_order_item.sql` - 子表 `order_item_id` 可空

### 3.2 后端 Service 层

后端 `ErpPurchaseReturnServiceImpl` 中的逻辑已经支持 `orderId` 为空的场景（三期开发时已实现）：

```java
// 1.2 校验采购订单已审核（orderId 可空）
ErpPurchaseOrderDO purchaseOrder = null;
if (createReqVO.getOrderId() != null) {
    purchaseOrder = purchaseOrderService.validatePurchaseOrder(createReqVO.getOrderId());
}
```

因此，前端不传 `orderId` 和 `orderItemId` 不会影响后端业务逻辑。

## 四、影响范围

### 4.1 功能影响

- ✅ **按入库单退货**：不受影响，仍然通过"原入库单"字段选择入库单
- ✅ **按库存退货**：不受影响，仍然通过"添加产品"按钮选择商品
- ❌ **按订单退货**（旧模式）：此模式已不再支持（前端入口已移除）

### 4.2 数据兼容性

- 历史数据中已有 `order_id` 和 `order_item_id` 的退货单**不受影响**，仍可正常查看和编辑
- 新建的退货单这两个字段为 NULL

### 4.3 相关组件

以下组件**不再使用**，但保留在代码库中（未删除）：
- `modules/purchase-order-select.vue` - 采购订单选择器
- `handleUpdateOrder` 函数 - 选择订单后的处理逻辑

如果之前未执行过以下脚本，需要执行：

```bash

mysql -u root -p ruoyi-vue-pro < sql/mysql/erp_purchase_return_v8_nullable_order.sql
```
