## 二、功能使用指南

### 2.1 访问字段配置页面

**路径**：ERP 系统 → 系统配置 → 字段配置

**URL**：`http://your-domain/erp/system/fieldconfig`

### 2.2 配置字段必填

1. **选择模块**：点击顶部Tab切换模块（采购订单/采购入库/采购退货/供应商）
2. **编辑字段**：
   - 字段中文名：可修改显示名称
   - 是否必填：开关切换（开=必填，关=选填）
   - 排序：调整字段在表单中的显示顺序
3. **保存配置**：点击"保存"按钮
4. **清空自定义**：点击"清空自定义"恢复默认配置

### 2.3 配置生效机制

**前端缓存**：
- TTL 5分钟自动失效
- 保存/重置后立即清除缓存
- 下次打开表单时重新加载配置

**生效时机**：
- 配置保存后，**下次打开表单**时生效
- 已打开的表单不受影响（需关闭重开）

### 2.4 配置规则说明

**软约束 vs 硬约束**：
- **前端软约束**：字段配置只影响表单展示（红星、空值校验）
- **后端硬约束**：数据库非空约束、Service业务校验保持不变
- 即使用户绕过前端也能被后端挡住

**规则识别**：
- `config.required = true` → 添加必填规则（红星 + 空值校验）
- `config.required = false` → 移除明显的必填规则（'required'、xxxRequired）
- 保留业务硬约束（如zod规则链、自定义校验函数）

## 四、常见问题

### 4.1 配置保存后不生效？

**原因**：前端缓存未失效

**解决**：
1. 关闭当前表单弹窗
2. 等待5分钟（缓存自动失效）
3. 或清除浏览器缓存（Ctrl+F5）
4. 重新打开表单

### 4.2 菜单找不到"字段配置"？

**原因**：菜单缓存未刷新

**解决**：
1. 系统管理 → 菜单管理 → 刷新缓存
2. 退出重新登录
3. 或重启后端服务

### 4.3 配置后仍然提示必填？

**原因**：后端硬约束（数据库非空、Service校验）

**说明**：
- 字段配置只影响前端展示
- 后端硬约束不受影响
- 这是设计行为，保证数据安全

### 4.4 供应商表单的sort和status字段？

**说明**：
- 这两个字段在八期已从表单移除
- 但字段配置表中仍保留记录
- 不影响使用，可忽略

## 五、技术架构

### 5.1 后端实现

**核心类**：
- DO：`ErpFieldConfigDO`
- Mapper：`ErpFieldConfigMapper`
- Service：`ErpFieldConfigService` + `ErpFieldConfigServiceImpl`
- Controller：`ErpFieldConfigController`
- Enum：`ErpFieldConfigModuleEnum`

**API端点**：
- `GET /erp/field-config/list?moduleKey=xxx` - 查询模块字段配置
- `PUT /erp/field-config/batch-update` - 批量保存
- `PUT /erp/field-config/reset?moduleKey=xxx` - 清空配置
- `GET /erp/field-config/modules` - 获取所有模块

### 5.2 前端实现

**核心文件**：
- API：`api/erp/config/field/index.ts`
- Composable：`views/erp/composables/useFieldConfig.ts`
- 管理页：`views/erp/system/fieldconfig/index.vue`

**表单接入**：
- 采购订单：`views/erp/purchase/order/modules/form.vue`
- 采购入库：`views/erp/purchase/in/modules/form.vue`
- 采购退货：`views/erp/purchase/return/modules/form.vue`
- 供应商：`views/erp/purchase/supplier/modules/form.vue`

**缓存机制**：
```typescript
// TTL 5分钟
const CACHE_TTL = 5 * 60 * 1000;

// 模块级缓存
const cache = new Map<string, { t: number; p: Promise<...> }>();

// 清除缓存
clearFieldConfigCache(moduleKey?: string)
```

### 5.3 数据库设计

**表名**：`erp_field_config`

**索引**：
- 主键：`id`
- 唯一索引：`uk_tenant_module_field` (tenant_id, module_key, field_name, deleted)
- 复合索引：`idx_module_key` (tenant_id, module_key, deleted)

**特性**：
- 支持多租户（tenant_id）
- 支持逻辑删除（deleted）
- 自动填充创建/更新信息（BaseDO）
